# Calculator-Android-App

A simple Android calculator app made using Android Studio.

The app can solve basic math problems and includes trigonometric functions like sin, cos, and tan. It also has a custom layout design, button animations, a dropdown menu, and a custom app logo.

## Features

- Basic calculator operations
- Trigonometric functions
- Custom calculator layout
- Button animations
- Dropdown menu for functions
- Custom app logo
- Simple and clean design

## Purpose

This app was built to practice Android app development and create a calculator with a more custom and interactive design.
